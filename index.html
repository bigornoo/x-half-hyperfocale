Sur le terrain
  1. Choisissez le mode d’exposition A ou M, puis réglez l’ouverture retenue sur la bague de diaphragme.
  2. Dans les réglages AF/MF, choisissez la mise au point manuelle.
  3. Tournez la bague de mise au point pour viser la distance calculée. L’indicateur de distance apparaît sur l’écran.
  4. Si l’échelle est trop peu précise, utilisez un sujet situé à une distance connue, puis vérifiez le résultat sur une photo.

La distance affichée est un repère théorique. L’échelle du boîtier ne permet pas forcément un réglage au centimètre. Le calculateur ne commande pas l’appareil.

En faisant le point plus loin que l’hyperfocale, l’infini reste dans la zone acceptable, mais la limite proche s’éloigne. La valeur affichée ici suppose une mise au point exactement à H.

Comprendre le calcul

H = f² / (N × c) + f

f = 10,8 mm, la focale réelle du X half. N est le nombre d’ouverture (par exemple 5,6) et c le cercle de confusion en millimètres. H est obtenu en millimètres, puis divisé par 1 000 pour l’affichage en mètres.

Lorsque la mise au point est faite à H, la limite proche est H / 2 et la limite lointaine est l’infini dans le modèle de lentille mince utilisé ici.

Pour une mise au point à une distance s, la formule cohérente avec ce H est : Dproche = s(H − f) / (H + s − 2f). En posant s = H, on obtient H / 2. Toutes ces longueurs doivent avoir la même unité.

Les distances sont mesurées depuis le plan principal de la lentille dans ce modèle. Sur l’appareil réel, elles restent des estimations. Les résultats sont arrondis au centimètre pour la lecture ; le calcul utilise toute la précision disponible.

Les trois cercles de confusion sont des critères de visualisation, pas des valeurs officielles imposées par Fujifilm. Plus le cercle choisi est petit, plus la netteté demandée est élevée et plus l’hyperfocale s’éloigne.

« Acceptable » ne signifie pas parfaitement net à chaque pixel. Le tirage, la distance d’observation, la diffraction, les défauts optiques et le mouvement influencent le résultat. Fermer à f/8 ou f/11 étend la profondeur de champ géométrique, mais la diffraction peut réduire les détails fins.

Installer sur l’iPhone
  1. Ouvrez l’adresse HTTPS de cette application dans Safari, avec une connexion Internet.
  2. Attendez le message « Prêt hors ligne » en bas de page.
  3. Touchez Partager, puis Sur l’écran d’accueil. Selon votre version d’iOS, le bouton Partager se trouve dans le menu de la page.
  4. Si l’option apparaît, activez Ouvrir comme app web, puis touchez Ajouter.
  5. Ouvrez l’icône Hyperfocale une première fois avec Internet et attendez à nouveau « Prêt hors ligne ». Testez ensuite en mode avion en désactivant aussi le Wi-Fi.

Le dossier ZIP ou un fichier ouvert depuis l’app Fichiers ne suffisent pas pour installer la version hors ligne. Un hébergement HTTPS est nécessaire pour le premier accès sur l’iPhone.

Les fichiers et vos derniers réglages restent dans le stockage local de l’app. Si iOS ou vous effacez ces données, rouvrez l’application avec Internet pour les recharger. Les liens vers les sources demandent une connexion.
