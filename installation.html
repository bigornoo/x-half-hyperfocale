Ouvrir le calculateur

X half · Hyperfocale

Une petite application de terrain, en français, à ajouter sur l’écran d’accueil de votre iPhone.

Les fichiers sont prêts à héberger. Ils ne sont pas encore publiés sur Internet ni installés sur votre iPhone. Le premier accès doit se faire depuis une adresse HTTPS ; le calculateur peut ensuite fonctionner sans connexion.

1. Mettre les fichiers en ligne

Décompressez x-half-hyperfocale.zip. Le dossier obtenu doit contenir directement index.html, les fichiers JavaScript et CSS, manifest.webmanifest, sw.js, ce guide et le dossier icons. Conservez leur organisation et leurs noms. Aucun logiciel de compilation ni serveur applicatif n’est nécessaire.

Avec un hébergement statique

Par exemple, Cloudflare Pages propose un dépôt de dossier par glisser-déposer :

  1. Connectez-vous à votre compte Cloudflare, puis ouvrez la rubrique Workers & Pages.
  2. Créez un projet Pages avec l’option de dépôt direct (Direct Upload / Drag and drop). Les libellés peuvent varier.
  3. Donnez un nom au projet et déposez le dossier de l’application. Vérifiez que index.html est à la racine des fichiers publiés.
  4. Lancez la publication et récupérez l’adresse HTTPS fournie en pages.dev. Elle servira à l’installation dans Safari.

Autre possibilité : un dépôt public avec GitHub Pages, disponible avec GitHub Free. Publiez ces mêmes fichiers et activez HTTPS dans les réglages Pages. Consultez la documentation officielle de GitHub Pages.

Avec votre hébergement actuel

Copiez tous les fichiers dans un dossier dédié, par exemple /hyperfocale/, et utilisez son adresse HTTPS terminée par /. Les chemins de l’application sont relatifs : un sous-dossier est pris en charge.

Le serveur doit servir sw.js comme JavaScript et le manifeste comme application/manifest+json ou JSON. Un fichier absent doit renvoyer une erreur 404, pas la page d’accueil. Pour les mises à jour, évitez un cache HTTP longue durée sur sw.js et index.html ; une politique Cache-Control: no-cache convient.

2. Installer dans Safari sur l’iPhone

  1. Ouvrez l’adresse HTTPS dans Safari, en navigation normale et avec Internet.
  2. Attendez le message Prêt hors ligne en bas de la page. Il confirme que tous les fichiers nécessaires sont présents dans le cache de l’application.
  3. Touchez Partager, puis Sur l’écran d’accueil. Selon l’interface de Safari, Partager se trouve dans le menu de la page.
  4. Si proposé, activez Ouvrir comme app web. Conservez le nom « Hyperfocale » puis touchez Ajouter.
  5. Ouvrez l’application depuis sa nouvelle icône, toujours avec Internet, et attendez Prêt hors ligne. Cette étape est utile car le stockage de l’app installée peut être distinct de celui de Safari.

La procédure officielle est décrite par Apple : transformer un site web en app. L’interface peut différer selon votre version d’iOS.

3. Vérifier le mode hors ligne

  1. Activez le mode avion et désactivez aussi le Wi-Fi.
  2. Fermez l’application, puis ouvrez-la à nouveau depuis son icône.
  3. Changez l’ouverture et le cercle de confusion : les distances doivent se recalculer immédiatement.
  4. Essayez f/5,6 et 0,011 mm : l’hyperfocale est 1,90 m et la limite proche 0,95 m.
  5. Les rubriques d’aide et le présent guide restent consultables. Les liens externes vers les sources nécessitent Internet.

Le calcul et la mémorisation des réglages sont locaux. Aucun compte n’est nécessaire dans l’application. Il n’y a ni bibliothèque distante, ni police à télécharger, ni publicité, ni télémétrie.

Le stockage web n’est pas une installation permanente garantie : une suppression des données de Safari/de l’app ou une éviction par iOS peut retirer le cache. Gardez une copie de l’archive et l’adresse HTTPS. Si nécessaire, rouvrez l’application en ligne et utilisez « Réessayer le téléchargement ». WebKit documente ces règles de stockage.

Les distances et la formule

H = f² / (N × c) + f, avec f = 10,8 mm, N = nombre d’ouverture et c = cercle de confusion en mm. Le résultat H est en millimètres ; il est divisé par 1 000 pour l’affichage en mètres.

Avec une mise au point exactement à H, la limite proche est H / 2 et la limite lointaine l’infini. Dans le modèle de lentille mince, la formule générale cohérente est Dproche = s(H − f) / (H + s − 2f). Elle donne H / 2 lorsque s = H.

On utilise la focale réelle de 10,8 mm, pas l’équivalent 24 × 36 de 32 mm. Les distances sont référencées au plan principal de la lentille dans ce modèle. L’application propose cinq ouvertures usuelles : f/2,8, f/4, f/5,6, f/8 et f/11. Le boîtier permet aussi des crans intermédiaires, non proposés dans cette version.

Les choix 0,011 / 0,008 / 0,005 mm représentent des exigences de netteté, pas une certification du constructeur. Une exigence plus élevée donne une hyperfocale plus éloignée. Le calcul ne modélise ni la diffraction ni les défauts optiques ni le mouvement. L’indicateur de distance du boîtier peut être trop peu précis pour reproduire exactement le résultat ; vérifiez vos images.

Note : à f/11 et c = 0,011 mm, H = 0,9747669… m, soit 0,97 m au centimètre le plus proche. Une valeur de 0,98 m correspond à un arrondi vers le haut, pas à l’arrondi usuel.

Pourquoi HTTPS ? Pourquoi pas simplement un fichier ?

Le service worker met les fichiers en cache pour les réouvertures hors ligne. Il doit être enregistré depuis une origine sécurisée. Sur l’iPhone, utilisez une adresse HTTPS avec un certificat valide. Ouvrir index.html dans Fichiers ou via une adresse file:// ne fournit pas cette installation. Un lien HTTP vers l’adresse locale d’un Mac ou d’un NAS ne suffit pas non plus.

L’exception http://localhost sert au développement sur le même appareil. Sur un iPhone, « localhost » désigne l’iPhone, pas votre Mac. Référence MDN sur les service workers.

Et une application native ou un raccourci ?

La PWA correspond bien à ce calculateur : icône dédiée, fenêtre autonome, interface complète et calcul hors ligne, sans passage par l’App Store ni compte développeur Apple.

Une application iOS native nécessiterait un projet distinct compilé et signé, typiquement avec Xcode sur Mac et un compte Apple. Un simple fichier .ipa non signé ne s’installe pas comme une application ordinaire. Avec une Personal Team gratuite, les profils de test expirent après 7 jours et l’app doit être reconstruite et réinstallée. La distribution classique via l’App Store demande l’adhésion au programme développeur et ses étapes de validation. Contraintes officielles Apple.

Un raccourci iOS local pourrait faire le même calcul avec deux menus et une alerte de résultat, sans hébergement. Il serait moins adapté au schéma, au tableau et aux réglages visibles simultanément. La version livrée ici est la PWA ; aucun raccourci ni paquet natif n’est inclus.

Fichiers et maintenance

  • index.html et style.css : interface française adaptée au mobile.
  • calculations.js : formule et paramètres du calcul.
  • app.js : interactions, mémorisation locale et état hors ligne.
  • manifest.webmanifest : nom, icônes et mode autonome.
  • sw.js : cache des fichiers, vérification et mises à jour.
  • icons/ : icône vectorielle, PNG 192 et 512 px, version maskable 512 px et icône Apple 180 px.
  • installation.html : ce guide, également disponible hors ligne.

Pour modifier l’application, changez les fichiers puis incrémentez VERSION dans sw.js. Publiez tous les fichiers ensemble. Une nouvelle visite en ligne téléchargera la nouvelle version ; un bouton « Mettre à jour » apparaîtra lorsqu’elle sera prête. Le remplacement recharge l’app ; les réglages mémorisés sont conservés.

Pour un aperçu sur un ordinateur équipé de Python, ouvrez un terminal dans le dossier décompressé :

python3 -m http.server 8765 --bind 127.0.0.1

Ouvrez ensuite http://localhost:8765/ sur cet ordinateur. Ce serveur de test ne rend pas l’application installable à distance sur l’iPhone.
